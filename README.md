# Predicción de Ventas con Regresión Lineal

Modelo de regresión lineal en Python (`modeloFinal.ipynb`) sobre `Productos_vendidos_portienda.csv` para analizar y predecir ventas.

## Contenido
- `modeloFinal.ipynb`: carga de datos, exploración, preprocesamiento, entrenamiento con `LinearRegression`, métricas (`R²`, `MAE`, `MSE`, `RMSE`) y visualizaciones.
- `Productos_vendidos_portienda.csv`: conjunto de datos de ventas por tienda.
